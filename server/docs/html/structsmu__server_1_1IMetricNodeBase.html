Detailed Description

The Base IMetricNode class to simplify the storage of data obtained from smu_server::make_root_node

First, you can create a smart pointer to IMetricNodeBase if you create nodes via factory methods in the module constructor, in which case you can get json by calling IMetricNodeBase::to_json().

Example usage

std::unique_ptr<IMetricNodeBase> m_root = make_root_node( ... );
Json::Value m_json = m_root->to_json();
