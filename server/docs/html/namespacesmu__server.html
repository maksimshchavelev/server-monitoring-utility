Creates a node that contains other nodes.

A container node can store other container nodes as well as values. Such nodes are assumed to be nested either in other container nodes or in the root node. If you need a root node, use smu_server::make_root_node

make_value_node("RAM usage", "4217", "MB")

Creates a root node.

Root nodes work the same way as container nodes, but they doesn't store own name

Parameters

Template Parameters
ChildrenTypes of nested nodes. Must inherit from internals::IMetricNode
Returns
std::unique_ptr with internals::MetricContainerNode<...>
Note
Call to_json on the root node to get the json and, for example, then send it over a websocket connection. However, this applies to all nodes, but it is used much more often with root nodes.

auto root = make_root_node(

Creates a node with the value.

A value node is a node that only stores a value. It cannot store other nodes.

Parameters
metric_nameMetric name
metric_valueMetric value. Can be either a number or a string
value_unitsMetric units
Template Parameters
ValueTypeValue type. Must be convertible to std::string, i.e., std::to_string can be called on it
Returns
std::unique_ptr with internals::MetricValueNode
See also
make_container_node and make_root_node

Example usage

// The metric value can be either a number or a string, it is converted
// to a string if needed
auto node = make_value_node("RAM usage", 4217, "MB");

This code gives json fragment:

{
"type": "value",
"units": "MB",
"value": "4217"
}
Note
The node name is only used if the node is nested in a container node or root node. A value node never contains its own name!
