Convert a numeric value from one textual unit to another SizeUnit.

Convert a numeric value from one textual unit to another SizeUnit.This function accepts a string describing the source units (case-insensitive), such as:

  • "b", "byte", "bytes"
  • "kb", "kbyte", "kbytes", "kilobyte", "kilobytes"
  • "mb", "mbyte", "mbytes", "megabyte", "megabytes"
  • "gb", "gbyte", "gbytes", "gigabyte", "gigabytes"
Note
Any unknown unit is treated as bytes.

The conversion is binary-based (1 KB = 1024 bytes, 1 MB = 1024 KB, etc.).

Parameters
source_unitsTextual representation of the source units (case-insensitive).
target_unitsTarget SizeUnit enumeration value.
valueThe original numeric value to convert.
Returns
Converted value represented in target_units.
Note
The function uses binary shifts, meaning all conversions are powers of two.

std::size_t r1 = SystemFileReader::convert_units("KB", SizeUnit::BYTES, 1); // r1 == 1024

std::size_t r2 = SystemFileReader::convert_units("mb", SizeUnit::KBYTES, 1); // r2 == 1024

std::size_t r3 = SystemFileReader::convert_units("bytes", SizeUnit::MBYTES, 1048576); // r3 == 1
