Detailed Description

template<typename... Children>
class smu_server::internals::IMetricNode< Children >

Interface IMetricNode class.

Is an interface (abstract) node class. Can be a node of any type

Template Parameters
ChildrenChild nodes. Must inherit from IMetricNode.
Note
This is an internal class for creating nodes. Use the factory methods smu_server::make_root_node, smu_server::make_container_node, smu_server::make_value_node for convenient and error-free node creation.
