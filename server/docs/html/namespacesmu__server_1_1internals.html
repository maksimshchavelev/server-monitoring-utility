Note

Example usage

// This is true
if constexpr (contains_substring("hello world", "WoRlD")) {
std::cout << "Contains WoRlD!" << std::endl;
}
// This is false
if constexpr (contains_substring("hello world", "abcd")) {
std::cout << "Contains abcd!" << std::endl;
} else {
std::cout << "Not contains abcd!" << std::endl;
}

Reads an unsigned 32-bit integer from memory in Big Endian order.

Example usage

If memory mem looks like this:

[0] : 0x00 (MSB)
[1] : 0x00
[2] : 0x00
[3] : 0x0C (LSB)

Then the code:

uint32_t val = read_uint32_be(mem, 0); // val will be 12
