Detailed Description

Implements a value node.

A value node can only store a value. Such a node does not contain any nested nodes.

Note
This is an internal class for creating nodes. Use the factory methods smu_server::make_root_node, smu_server::make_container_node, smu_server::make_value_node for convenient and error-free node creation.

Example

For example, if we pass:

  • node_name = "RAM usage"
  • node_value = "5740"
  • value_units = "MB"

Then calling the to_json method will return the following JSON:

{
"type": "value",
"value": "5740",
"units": "MB"
}

Please note that the value node does not store its name. To get the name, call get_name
